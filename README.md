# ФОРМАТ — печатный планировщик

Статический сайт без сборки: один файл `index.html`.

## Деплой на Vercel
1. Загрузите папку в GitHub-репозиторий (или перетащите её в Vercel → Add New → Project).
2. Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми.
3. Deploy. Через CLI: `npx vercel --prod` из этой папки.

## Данные
Хранятся в `localStorage` браузера на вашем устройстве и привязаны к адресу сайта
(другой домен или превью-URL Vercel покажет пустые данные). Сохранение идёт при каждом
изменении, при сворачивании и закрытии вкладки. Между устройствами данные не переносятся.
